# Coffee Website

A responsive website for a coffee shop, built with HTML, CSS and vanilla JavaScript.

## Features

- Home page with a hero section and a "Favorite Menu" of 8 coffees
- Full menu page with a category filter (Coffee, Cold Drinks, Hot Drinks, Pastries, Meals)
- Products loaded dynamically from a `products.json` file
- Cart side panel (open / close)
- Responsive design with a mobile hamburger menu

## Work in progress

- Add to Cart logic (quantities, total)
- Checkout

## Run locally

Open the project with the VS Code "Live Server" extension (the products are loaded with `fetch`, so opening the file directly does not work).

## Built with

HTML5, CSS3 (Grid, Flexbox), JavaScript, Font Awesome, Poppins and Miniver fonts.
